# 递归算法的时间复杂度分析

计算递归函数的时间复杂度通常有三种常用方法：**递归树法**、**主定理 (Master Theorem)** 和 **代入法**。

## 1. 主定理 (Master Theorem)
这是解决**分治算法**（如归并排序、二分查找、快速幂）复杂度最快的方法。

针对形如 **$T(n) = a \cdot T(n/b) + f(n)$** 的递推公式：
- $n$: 问题规模
- $a$: 子问题个数 (递归调用的次数)
- $b$: 子问题缩小的倍数
- $f(n)$: 把原问题分解为子问题和合并子问题的代价

### 判别法则：
比较 $n^{\log_b a}$ 和 $f(n)$ 的增长速率：

1. **$n^{\log_b a} > f(n)$** (子问题主要耗时)  
   $\Rightarrow T(n) = O(n^{\log_b a})$
   *例子：树的遍历*

2. **$n^{\log_b a} = f(n)$** (势均力敌)  
   $\Rightarrow T(n) = O(n^{\log_b a} \log n)$
   *例子：归并排序 ($a=2, b=2, f(n)=n$) $\Rightarrow O(n \log n)$*
   *例子：二分查找 ($a=1, b=2, f(n)=1$) $\Rightarrow O(\log n)$*

3. **$n^{\log_b a} < f(n)$** (分解/合并主要耗时)  
   $\Rightarrow T(n) = O(f(n))$

---

## 2. 递归树法 (Recursion Tree)
当主定理不适用时（例如子问题规模不一致 $T(n) = T(n/3) + T(2n/3) + n$），可以画出递归树。
- **画出树结构**：每层节点的代价。
- **求和**：计算每一层代价的总和。
- **分析**：看总和是随着层数指数增长、递减还是保持不变。

---

## 3. 实例分析：即使是刚才的 `myPow(x, n)`

代码结构：
```python
def quick_mul(N):
    if N == 0: return 1.0
    y = quick_mul(N // 2)  # 1次递归调用
    return y * y if ...    # O(1) 的合并操作
```

**分析过程**：
1. **递推公式**：
   - 每次问题规模减半：$n \rightarrow n/2$
   - 每次只调用一次递归：$a = 1$
   - 函数内部其他操作（乘法、判断）是常数时间：$f(n) = O(1)$
   - 公式：$T(n) = T(n/2) + O(1)$

2. **套用主定理**：
   - $a = 1, b = 2$
   - 计算临界值：$n^{\log_b a} = n^{\log_2 1} = n^0 = 1$
   - $f(n) = 1$
   - 属于 **Case 2** ($n^{\log_b a} = f(n)$)
   - 结果：$T(n) = O(1 \cdot \log n) = O(\log n)$

这就是为什么快速幂算法比普通的 $O(n)$ 循环乘法要快得多的原因。
